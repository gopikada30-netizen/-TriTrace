# TriTrace Research Methodology

## 1. Problem Formulation
Code authorship classification is framed as estimating the posterior probability of authorship source $Y \in \{0, 1\}$ given an observed source code token sequence $X$:
- $Y = 0$: Human-authored source code from verified open-source repositories.
- $Y = 1$: Synthetic source code generated by large language models (LLMs).

To mitigate overconfidence in forensic analysis, TriTrace employs selective classification with abstention threshold $\tau$:
$$\hat{y}(X) = \begin{cases} \arg\max_k p_k(X) & \text{if } \max_k p_k(X) \ge \tau \\ \text{Abstain ("Uncertain")} & \text{otherwise} \end{cases}$$

## 2. Feature Extraction Methodology

### A. AST Metrics
Extracted using language-specific syntax parsers (`ast` for Python; regex token stream fallback for C++, Java, JS/TS):
- Depth profiles: nesting depth, maximum tree height.
- Density metrics: branch density ($N_{\text{branch}} / N_{\text{nodes}}$), expression density, return statement density.
- Paradigm markers: list/dict comprehension frequencies, lambda counts.

### B. Stylometric Metrics
- **Vocabulary Richness:** Type-Token Ratio ($V / N$), token Shannon entropy.
- **Pattern Repetition:** Fraction of repeated token bigrams and trigrams.
- **Formatting Signatures:** Line length standard deviation, blank line ratios.

## 3. Training Protocol
- **Optimizer:** AdamW with decoupled weight decay ($\lambda = 0.01$).
- **Learning Rate:** $3 \times 10^{-4}$ with linear warmup.
- **Batch Size:** 4.
- **Loss Function:** Calibrated cross-entropy loss.
- **Data Partitioning:** Repository-isolated splitting (train, validation, test) ensuring zero repository or author overlap between training and evaluation splits.

## 4. Temperature Calibration
Deep models frequently produce uncalibrated overconfident probabilities. The logit vector $z$ is scaled by temperature parameter $T > 0$:
$$p_i = \frac{e^{z_i / T}}{\sum_j e^{z_j / T}}$$
$T$ is optimized on the held-out validation set minimizing Negative Log Likelihood (NLL).

Expected Calibration Error (ECE) is quantified across $M = 10$ bins:
$$\text{ECE} = \sum_{m=1}^M \frac{|B_m|}{N} \left| \text{acc}(B_m) - \text{conf}(B_m) \right|$$

## 5. Token Attribution (Gradient x Input)
Token saliency reflects the sensitivity of the predicted logit $\hat{z}_{\hat{y}}$ to each input embedding:
$$S(t_i) = \left| \sum_{d=1}^D \frac{\partial \hat{z}_{\hat{y}}}{\partial e_{i, d}} \cdot e_{i, d} \right|$$
Attribution scores are normalized to $[0, 1]$ and categorized into High, Medium, and Low intensity spans for interactive inspection.
